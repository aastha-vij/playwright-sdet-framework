# Playwright SDET Framework

A production-style Playwright automation framework built with JavaScript.

## Technology Stack

- Playwright
- JavaScript
- Node.js
- npm

## Application Under Test

[SauceDemo](https://www.saucedemo.com/)

## Current Automation Scope

- Authentication
- Products
- Shopping Cart
- Checkout
- Order Completion

## Browser

Currently supported:

- Google Chrome

Additional browsers will be added during the cross-browser testing phase.

🚧 Framework implementation in progress.
