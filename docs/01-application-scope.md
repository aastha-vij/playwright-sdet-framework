## Functional Areas

The automation framework will cover:

- Authentication

- Product details

- Checkout

## Automation Scope

The framework will demonstrate:

- UI automation
- Functional testing
- Negative testing
- Smoke testing
- Regression testing
- End-to-end testing
- Data-driven testing
- Cross-browser testing
- CI/CD execution
- Test reporting
